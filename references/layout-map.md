# 레이아웃 선택 지도

아래는 형태 선택을 위한 지도다. 샘플의 내용·행 수·페이지 수를 새 자료의 요구사항으로 취급하지 않는다.

| 필요한 장표 | 원본 PDF | 편집 가능한 PPTX 예 | 적용 요령 |
|---|---|---|---|
| 표지 | 1쪽 | 1쪽 | 대각선 사진 배경과 왼쪽 제목, 하단 브랜드 |
| 연혁·비교·구조 | 2~3, 20쪽 | 2, 4, 6, 12쪽 | 보라색 표 머리행, 연한 분류 열과 회색 행 |
| 단계별 진행 | 4쪽 | 16쪽 | 실제 단계 관계에 맞춰 구성, 단계를 임의로 추가하지 않음 |
| 큰 화면과 짧은 설명 | 6, 10쪽 | 3, 8, 10, 11, 14, 20쪽 | 화면은 크게, 설명은 보라색 소제목과 회색 영역 |
| 제품 역할·구성 | 33쪽 | 5쪽 | 역할별 묶음과 하단 결합 설명, 필요한 수만 배치 |
| 상세 원본 도해 | 3쪽 | 7쪽 | 관계·레이블을 보존하고 확대 배치 |
| 큰 값·판단 비교 | 2쪽 | 19쪽 | 수치와 상태를 크게, 기준과 단위는 가까이 |
| 정리·다음 단계 | 33, 43쪽 | 22쪽 | 보라색 범주와 간결한 설명, 새 성과 주장 금지 |

`assets/style-previews/`에는 원본 PDF 1, 2, 4, 6, 10, 20, 33쪽이 있고, `assets/example-previews/`에는 적용 PPTX 2, 3, 5, 8, 9쪽이 있다. 전체 배치를 다시 확인할 때는 보존된 원본 파일을 렌더링한다.

## 스타일 전환 완료 기준

- 원본 입력 자료와 결과의 장수·순서·주요 문장·표 값·차트 데이터·스크린샷이 유지됐다. 내용 변경 요청이 있으면 그 범위만 달라졌다.
- 표지와 본문 모두 원본 PDF의 시각 언어를 따른다. 보라색으로만 바꾼 기존 디자인을 완성본으로 간주하지 않는다.
- 표·차트·텍스트는 편집 가능하고 원본 도해와 실제 화면이 선명하다.
- 모든 장을 실제 크기로 확인했고 제목·로고, 표 셀, 캡션·하단 번호의 겹침이 없다.
- 사용자 자료에 없는 고객명·사례·성과·법률 기준이 템플릿에서 유입되지 않았다.
